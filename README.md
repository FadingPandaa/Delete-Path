📖 Project Overview

This project is a Java-based application focused on file and directory management, specifically deleting user-specified paths. It demonstrates how Java interacts with the file system while applying core programming concepts.

Key concepts covered:

- File handling in Java
- User input processing
- Conditional logic
- Error handling
- Object-Oriented Programming (OOP)

---------------------------------------------------------------------------------
🚀 Features

✅ Accepts user-defined file or directory paths
✅ Deletes files or directories
✅ Validates path existence
✅ Handles invalid input scenarios
✅ Simple and structured program flow

--------------------------------------------------------------------------------------
▶️ How to Run

Using NetBeans:
1. Open NetBeans
2. Load the project
3. Click Run

-----------------------------------------------------------------------------------
🔄 How It Works

1. User inputs a file or directory path
2. Program checks if the path exists
3. If valid:
  - File/directory is deleted
4. If invalid:
  - Error message is displayed

-------------------------------------------------------------------------------------
⚠️ Limitations

- No confirmation prompt before deletion
- No recovery/undo functionality
- Limited error handling
- Console-based interaction only
